## `houdini/`
A Houdini plugin which provides an SLX Material node, decompilation tools and allows users to create a 
library of nodes using SLX which can be re-used in other MaterialX material builders. See [houdini/README.md](houdini/README.md).

## `vscode_extension/`
A VSCode extension which supports syntax highlighting, code completion using `ctrl+space` and code navigation using `ctrl+click`, reports
errors as you type and displays information as you hover over code. It also includes the ShadingLanguageX SKILL.md for
AI agents which can be queried as you work. See [vscode_extension/README.md](vscode_extension/README.md).
