# JavaScript API

The WebAssembly module, `JsMxslc.js`, from the `mxslc_JsMxslc_package.zip` release asset. The module is an ES6 module
whose default export loads it:

```javascript
import Mxslc from './JsMxslc.js';

const mx = await Mxslc();
const opts = new mx.CompileOptions();
const mtlx = mx.compileSlxToMtlx('float x = add(1.0, 2.0);', opts);
const slx = mx.decompileMtlxToSlx(mtlx);
opts.delete();
```

Objects created with `new` must be freed with `delete()`. The declarations below are generated by the build and are also
in the release asset as `JsMxslc.d.ts`.
